# 功能说明

本文档描述拾光集的功能范围、数据模型与典型使用流程，是理解系统的入口。

---

## 一、功能清单

| 功能 | 说明 | 对应 API / 页面 |
|------|------|----------------|
| 登录获取令牌 | 返回 JWT，后续请求带 `Authorization: Bearer <token>` | `POST /api/auth/login` |
| 当前用户 | 校验令牌并返回用户信息（含 `is_admin`） | `GET /api/auth/me` |
| **管理员-用户管理** | 查看用户列表 / 创建用户 / 删除用户（仅管理员） | `GET/POST/DELETE /api/admin/users` |
| 物品管理 | 增删改查，含名称/描述/数量/单位/价格/状态/保质期/购买日期/序列号/保修到期/位置/分类 | `/api/items` |
| 物品搜索 | 按关键词（名称/描述/备注）、状态、分类、位置、标签组合筛选 | `GET /api/items?keyword=&status_filter=&category_id=&location_id=&tag_id=` |
| 物品分页 | 每页 N 条，翻页导航 | `GET /api/items?page=1&page_size=20` |
| 物品编辑 | 每行「编」按钮，表单回填，部分更新 | `PUT /api/items/{id}` |
| **物品归档** | 标记已用完/已丢弃的物品，默认隐藏，可查看 | `POST /api/items/{id}/archive` |
| **批量操作** | 勾选多个物品 → 批量归档/删除/改状态/改分类 | `POST /api/items/batch` |
| **序列号+保修** | 记录数码产品/家电的序列号和保修到期日 | `/api/items`（字段） |
| **资产价值** | 记录物品价格，概览页显示总资产和分类资产 | `GET /api/dashboard/summary` |
| **借用记录** | 记录物品借给谁、借出日期、预计归还、归还状态 | `/api/items/{id}/borrows` |
| **操作日志** | 物品创建/修改/删除自动记录，含字段级变更对比 | `GET /api/items/{id}/logs` |
| **QR 码生成** | 每件物品生成二维码 PNG，可打印贴箱 | `GET /api/items/{id}/qrcode` |
| **自动备份** | 定时备份 SQLite 数据库，保存 48 份，支持手动触发和恢复 | `/api/backups` |
| **CSV 导入导出** | 导出物品 CSV/ZIP 存档；上传 CSV 批量导入 | `GET/POST /api/export /import` |
| 图片上传 | 拍照上传 → 自动 WebP 压缩 → 超 2000px 缩放 → 缩略图预览 | `POST/GET/DELETE /api/items/{id}/images` |

## 二、数据模型

> 所有业务数据带 `owner_id`，实现多用户隔离。时间字段为服务端时区。

| 模型 | 关键字段 | 说明 |
|------|---------|------|
| **User** | `id, username(unique), hashed_password, is_admin, created_at` | 账号（管理员标记） |
| **Location** | `id, name, parent_id(FK 自引用), note, owner_id` | 层级位置 + 备注 |
| **Category** | `id, name, color, owner_id` | 分类/标签（单选）|
| **Tag** | `id, name, color, owner_id` | 标签（多对多）|
| **Item** | `id, name, description, location_id, location_note, category_id, quantity, unit, status, price, expiry_date, purchase_date, serial_number, warranty_expiry, archived, owner_id, created_at, updated_at` | 核心实体 |
| **ItemImage** | `id, item_id(FK), filename, original_name, width, height, file_size` | 物品图片（一对多）|
| **BorrowRecord** | `id, item_id(FK), borrower_name, borrow_date, expected_return_date, return_date, notes` | 借用记录 |
| **ItemLog** | `id, item_id(FK), user_id, action, summary, created_at` | 操作日志（审计追踪）|
| **PushSubscription** | `id, user_id(FK), endpoint, auth_key, p256dh_key` | Web Push 订阅 |
| **ItemStatus** | 枚举：`在库 / 已借出 / 损坏 / 待处理 / 已丢弃` | 状态字典 |

### 关系

```
User 1 ── * Item / Location / Category / Tag / PushSubscription
Location 1 ── * Location (自引用 parent_id，层级树)
Item ── Location (location_id, ondelete=SET NULL)
Item ── Category (category_id, ondelete=SET NULL)
Item ── * Tag (多对多，通过 item_tags 关联表)
Item ── * ItemImage (一对多，ondelete=CASCADE)
Item ── * BorrowRecord (借用记录，ondelete=CASCADE)
Item ── * ItemLog (操作日志，ondelete=CASCADE)
Item ── location_note (自由备注，与层级位置互补)
```

## 三、状态字典（ItemStatus）

| 值 | 含义 |
|----|------|
| `在库` | 正常存放 |
| `已借出` | 被借走，不在手中 |
| `损坏` | 损坏不可用 |
| `待处理` | 待维修/待处置 |
| `已丢弃` | 已丢弃/消耗完 |

> 扩展状态：在 `app/models/status.py` 的 `ItemStatus` 枚举中增加值即可，前后端同步。

## 四、典型使用流程

1. **注册 / 登录**：浏览器打开首页 → 跳登录页 → 注册 → 自动登录。
2. **建位置层级**：位置页添加顶层位置 → 添加子位置（下拉选择父级）。
3. **建分类**：分类页添加「食品」「工具」并选颜色。
4. **建标签**：标签页添加「易碎」「贵重」「需冷藏」等。
5. **记物品**：物品页填写名称、选位置、选分类、选标签、数量、价格、状态、序列号、保修、保质期、上传图片。
6. **编辑物品**：物品列表点「编」→ 表单回填 → 改 → 保存。
7. **筛物品**：按关键词、状态、分类、位置、标签组合筛选。
8. **翻页**：物品多时通过页码导航浏览。
9. **批量操作**：勾选多个物品 → 底部操作栏 → 批量归档/删除/改状态/改分类。
10. **归档**：已用完的物品点「归档」隐藏，勾选「显示已归档」可查看或取消归档。
11. **借用管理**：点「借」→ 弹窗记录借用人/日期/预计归还 → 到期归还标记。
12. **看概览**：概览页查看总数、状态分布、分类分布、**资产总值**、过期提醒。
13. **操作日志**：点「日志」查看物品的所有修改记录（时间线 + 字段级变更）。
14. **二维码**：点「◈」生成二维码 PNG，可打印贴在箱子/物品上。
15. **备份**：备份页查看每小时自动备份，可手动触发或选择备份恢复。
16. **CSV 导入导出**：物品页「导出 CSV」下载数据；「导入 CSV」批量上传。
17. **收推送**：允许通知后，物品过期前 3 天自动收到浏览器推送。

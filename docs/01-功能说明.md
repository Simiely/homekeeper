# 功能说明

本文档描述拾光集的功能范围、数据模型与典型使用流程，是理解系统的入口。

---

## 一、功能清单

| 功能 | 说明 | 对应 API / 页面 |
|------|------|----------------|
| 登录获取令牌 | 返回 JWT，后续请求带 `Authorization: Bearer <token>` | `POST /api/auth/login` |
| 当前用户 | 校验令牌并返回用户信息（含 `is_admin`） | `GET /api/auth/me` |
| **管理员-用户管理** | 查看用户列表 / 创建用户 / 删除用户（仅管理员） | `GET/POST/DELETE /api/admin/users` |
| 物品管理 | 增删改查，含名称/描述/数量/单位/价格/状态/保质期/保质期天数/生产日期/序列号/条形码/保修到期/位置/分类 | `/api/items` |
| 物品搜索 | 按关键词（名称/描述/备注/**位置名/分类名/标签名/序列号/条码**）、状态、分类、位置、**标签多选**组合筛选 | `GET /api/items?keyword=&status_filter=&category_id=&location_id=&tag_ids=&sort=` |
| 物品排序 | **4 种排序**：最新添加（默认）/ 按保质期 / 按位置 / 按分类 | `GET /api/items?sort=expiry|location|category` |
| 物品分页 | 每页 N 条，翻页导航 | `GET /api/items?page=1&page_size=20` |
| 物品编辑 | 详情卡片「编辑」→ 独立添加页 `#/add?id=N` 回填保存 | `PUT /api/items/{id}` |
| **物品已处理** | 标记已处理/损坏丢弃，默认隐藏，可查看或撤销 | `POST /api/items/{id}/archive` |
| **批量操作** | 勾选多个物品 → 批量归档/删除/改状态/改分类 | `POST /api/items/batch` |
| **序列号+保修** | 记录数码产品/家电的序列号和保修到期日 | `/api/items`（字段） |
| **资产价值** | 记录物品价格，归处页底部边缘显示总资产 | `GET /api/dashboard/summary` |
| **借用记录** | 记录物品借给谁、借出日期、预计归还、归还状态 | `/api/items/{id}/borrows` |
| **操作日志** | 物品创建/修改/删除自动记录，含字段级变更对比 | `GET /api/items/{id}/logs` |
| **QR 码生成** | 每件物品生成二维码 PNG，可打印贴箱 | `GET /api/items/{id}/qrcode` |
| **自动备份** | 定时备份 SQLite 数据库，保存 48 份，支持手动触发和恢复 | `/api/backups` |
| **CSV 导入导出** | 导出物品 CSV/ZIP 存档；上传 CSV 批量导入 | `GET/POST /api/export /import` |
| 图片上传 | 拍照上传 → 自动 WebP 压缩 → 超 2000px 缩放 → 缩略图预览 | `POST/GET/DELETE /api/items/{id}/images` |

## 二、数据模型

> 所有业务数据带 `owner_id`，实现多用户隔离。时间字段为服务端时区。

| 模型 | 关键字段 | 说明 |
|------|---------|------|
| **User** | `id, username(unique), hashed_password, is_admin, created_at` | 账号（管理员标记） |
| **Location** | `id, name, parent_id(FK 自引用), note, owner_id` | 层级位置 + 备注 |
| **Category** | `id, name, color, owner_id` | 分类/标签（单选）|
| **Tag** | `id, name, color, owner_id` | 标签（多对多）|
| **Item** | `id, name, description, location_id, location_note, category_id, quantity, unit, status, price, expiry_date, purchase_date, shelf_life_days, serial_number, barcode, warranty_expiry, archived, owner_id, created_at, updated_at` | 核心实体 |
| **ItemImage** | `id, item_id(FK), filename, original_name, width, height, file_size` | 物品图片（一对多）|
| **BorrowRecord** | `id, item_id(FK), borrower_name, borrow_date, expected_return_date, return_date, notes` | 借用记录 |
| **ItemLog** | `id, item_id(FK), user_id, action, summary, created_at` | 操作日志（审计追踪）|
| **PushSubscription** | `id, user_id(FK), endpoint, auth_key, p256dh_key` | Web Push 订阅 |
| **ItemStatus** | 枚举：`在库 / 临期 / 定期处理 / 已处理 / 损坏丢弃` | 状态字典 |

### 关系

```
User 1 ── * Item / Location / Category / Tag / PushSubscription
Location 1 ── * Location (自引用 parent_id，层级树)
Item ── Location (location_id, ondelete=SET NULL)
Item ── Category (category_id, ondelete=SET NULL)
Item ── * Tag (多对多，通过 item_tags 关联表)
Item ── * ItemImage (一对多，ondelete=CASCADE)
Item ── * BorrowRecord (借用记录，ondelete=CASCADE)
Item ── * ItemLog (操作日志，ondelete=CASCADE)
Item ── location_note (自由备注，与层级位置互补)
```

## 三、状态字典（ItemStatus）

| 值 | 含义 |
|----|------|
| `在库` | 正常存放，随时可用 |
| `临期` | 临近保质期（由保质期天数/到期日驱动提醒） |
| `定期处理` | 需要定期维护/处理（如滤芯、电池） |
| `已处理` | 已用完/已清理/已归档，默认隐藏，可查看或撤销 |
| `损坏丢弃` | 已损坏或丢弃 |

> 扩展状态：在 `app/models/status.py` 的 `ItemStatus` 枚举中增加值即可；前端状态选项由 `GET /api/meta` 单源拉取（`items.js` / `add.js` 用返回覆盖本地兜底值），无需改前端。

## 四、典型使用流程

1. **登录**：浏览器打开首页 → 跳登录页 → 输入账号密码（账号由管理员在「用户管理」页创建，默认禁止公开注册）。
2. **建位置层级**：位置页卡片右侧 `+` 添加子位置（内联表单）；点「✎ 编辑」进入编辑模式（**自动收起展开的物品列表，退出后恢复**），**单击卡片改名、拖动卡片调整层级**（拖到屏幕边缘页面自动滚动）；非编辑模式点击项目条展开/收起物品列表（多个展开状态自动记入 URL，可逐级后退恢复）。
3. **建分类**：分类页添加「食品」「工具」并选颜色。
4. **建标签**：标签页添加「易碎」「贵重」「需冷藏」等。
5. **记物品（添加页 `#/add`）**：点顶栏 **＋** 进入独立添加页——扫码或输入条码（曾录入过的会自动回填名称/位置/数量等信息，**保质期除外**）；表单分 6 组：条码 / 基本信息（名称*、存放位置*、位置备注、描述、分类）/ 照片*（必填）/ 保质期 / 数量与状态 / 更多信息（标签按钮多选+可新建、价格、保修到期、序列号）；**名称、存放位置、照片三项必填**。
6. **编辑物品**：物品页点左侧列表行 → 右侧详情卡片展示完整信息 → 点「编辑」进入 `#/add?id=N` 回填修改 → 保存返回并选中该物品。
7. **筛物品**：按关键词、状态、分类、位置、**标签多选（chips）**、**排序（最新添加/保质期/位置/分类）**组合筛选（条件记入 URL，刷新保留）。
8. **翻页**：物品多时通过页码导航浏览。
9. **批量操作**：勾选多个物品 → 底部操作栏 → 批量已处理/删除/改状态/改分类。
10. **已处理**：已用完/损坏的物品在详情卡片点「已处理」隐藏，勾选「显示已处理」可查看或撤销。
11. **借用管理**：详情卡片点「借」→ 弹窗记录借用人/日期/预计归还 → 到期归还标记。
12. **找东西（归处）**：打开「归处」页 → 顶部全局搜索框输入物品/位置/分类/标签名 → 结果直接显示存放位置路径（可点跳转）；或在「常用位置」点位置直达。
13. **清临期（归处）**：归处页「临期清理」板块：已过期/临期分段展示，每行左侧「已处理」按钮 → 确认后标记并从临期清单消失。
14. **操作日志**：详情卡片点「日志」查看物品的所有修改记录（时间线 + 字段级变更，口语化中文）。
15. **二维码**：点「◈」生成二维码 PNG，可打印贴在箱子/物品上。
16. **备份**：备份页查看每小时自动备份，可手动触发或选择备份恢复。
17. **CSV 导入导出**：物品页「导出 CSV」下载数据；「导入 CSV」批量上传。
18. **收推送**：允许通知后，物品保质期/保修期到期前 3 天自动收到浏览器推送。
19. **URL 回溯**：每个视图/展开/搜索状态都有独立网址，浏览器前进/后退可逐级回溯浏览轨迹，刷新页面状态不丢。

## [v0.9.12] - 2026-08-03

### 添加/编辑页布局重排 + 三个必填

#### 变更
- **分组顺序重排**（按用户列出的顺序）：
  1. 条码
  2. 基本信息（物品名称*、**存放位置\***、位置备注、描述、分类）
  3. **照片**（必填，从原第六位上移）
  4. 保质期
  5. 数量与状态
  6. 更多信息
- **更多信息内字段顺序**：标签 → 价格（元） → 保修到期 → 序列号（之前是 序列号→价格→保修→标签）
- **存放位置并入基本信息组**（位置独立分组占用一个位置，与用户列的 6 组冲突；并入更紧凑）
- **收紧表单间距**：`.add-form` gap 16→10px、`.form-group` padding 12px→10px / gap 10→8px、`.add-head` margin-bottom 14→10px

#### 必填校验
- **物品名称**（原已有 `required`）
- **存放位置**（新增 `required` + 占位文案"请选择位置"）
- **照片**（新增必填）：
  - **添加模式**：必须选择照片才能保存
  - **编辑模式**：照片区改为可见（之前隐藏），预览当前首图；用户可选新图覆盖（追加到相册）；提交校验"已有图 OR 新选了图"
- 表单加 `novalidate`，全部走 `showDialog` 程序弹窗校验（替代浏览器原生气泡，保持 nativeDialogs=0 规范）

#### 上传逻辑调整
- 编辑模式新选照片也会上传（POST /items/{id}/images 追加到相册）

## [v0.9.11] - 2026-08-02

### 添加/编辑物品页标签改版：按钮式多选 + 直接新建

#### 变更
- 标签输入从「按住 Ctrl 多选的 multiple select」改为**按钮式 chips 多选**：
  - 每个标签一个按钮（`.tag-opt`），点击切换选中态
  - **选中**：accent 粉色高亮 + 加粗 + 外环阴影（box-shadow）；**未选中**：灰色（muted 文字 + 边框）
  - 编辑回填：已有标签自动置为选中态

#### 新增
- **直接新建标签**：标签区下方新增输入行「新标签名，回车即创建并选中」+「＋ 新标签」按钮：
  - 输入名称回车 / 点按钮 → 立即创建（POST /api/tags）→ 自动加入标签区并置为选中
  - **同名标签不重复创建**：已存在同名标签时直接选中它
  - 创建失败弹程序提示框

#### 修复
- `.card button`（accent 填充）覆盖 `.ghost` / `.tag-opt` 的问题：新增 `.card .ghost`、`.card .tag-opt` 更高优先级规则（添加页内所有 ghost 按钮与标签按钮恢复正常样式，含此前潜伏的「取消」按钮被误染成主色问题）

#### 说明
- 新建标签若最终未保存物品（点取消），标签仍会保留在标签库（可在「标签」页删除），属预期行为

## [v0.9.10] - 2026-08-02

### 物品页优化：排序 + 标签多选 + 列表行位置突出 + 表单字段标注

#### 新增
- **物品排序**：筛选栏新增排序下拉 `#f-sort`，4 种排序模式：
  - 最新添加（默认）：按创建时间倒序
  - **按保质期排序**：到期日升序，无保质期物品排最后
  - **按位置排序**：按位置的 `sort_order → 名称` 升序（无位置物品排最后），同位置内按最新在前
  - **按分类排序**：按分类名升序（中文按 Unicode 码点），同类内按最新在前
- **标签筛选多选**：原标签单选下拉改为 **chips 多选**（点击 chip 切换 active，accent 边框高亮 + 加粗）；URL `tag_ids=1&tag_ids=2` 数组参数；后端 `IN` 查询并集匹配；一个物品有任一选中标签即命中

#### 变更
- **列表行重设计**：第一行 名称(加粗) + 状态 chip + **保质期角标（贴右上角）**；第二行 **📍 位置路径（accent 色 + 加粗 13px 突出）**；第三行 `数量+单位 · 分类`（muted）。位置是核心诉求——一眼看到东西在哪
- **添加页表单加字段标签**：每个字段 `label + input` 上下结构（替代仅 placeholder 容易看漏）：
  - 物品名称 \*、描述、分类、位置、位置备注、数量、单位、状态
  - 保质期天数、**生产日期**（用户原话"如果是生产日期，你也需要写出来"——保质期按 生产日期+天数 计算）、保质期到期
  - 序列号、**价格（元）**、保修到期、标签、条码
- 详情卡片字段名 `购买日期` → **生产日期**（与表单一致）

#### 后端
- `item_service.list_items` 新增 `sort` 参数 + `tag_ids: list[int]` 多标签 IN 查询（distinct 防重复计数）
- `routers/items.py` 暴露 `sort`（regex 校验 `^(newest|expiry|location|category)$`，非法值 422） + `tag_ids: list[int]` query 参数
- `tag_id` 单选参数保留向后兼容（内部改用 `distinct()` 顺手修复原计数隐患）

## [v0.9.6] - 2026-08-02

### 位置体验与 URL 路由（⭐ 重点）

#### 新增
- **hash 路由（每页独立 URL）**：每个视图有独立地址（`#/dashboard`、`#/items`、`#/locations`），浏览器**前进/后退逐级回溯**（从「位置」后退回「归处」）；刷新页面停留在原视图
- **视图内状态同步 URL**：首页搜索词 `?q=`、位置展开 `?open=4&open=7`（支持多层级）、物品筛选 `?kw=&status_filter=&category_id=`——均可分享、刷新保留、后退恢复
- **展开状态逐级后退**：展开位置 A → 展开位置 B → 后退一步回到 A（展开操作记入历史）
- **位置拖拽边缘自动滚动**：触屏拖拽时手指移到视口上/下边缘（80px 区），页面自动跟随滚动（步长 26px/帧），可把卡片拖到屏幕外的目标位置
- **编辑模式自动收起物品**：点「✎ 编辑」暂时收起所有已展开的物品列表（展开状态保留），点「✔ 完成」退出后自动恢复
- 位置聚焦高亮：从首页常用位置跳转，折叠无关分支、仅高亮目标位置（2.6s 消退，不波及嵌套子位置）

#### 修复
- 位置聚焦高亮误伤嵌套子位置（后代选择器 → 直接子级选择器）
- 多层级展开后退只恢复一个 → URL 支持多 `open` 参数（`?open=4&open=7`）

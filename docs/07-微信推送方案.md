# 微信推送方案

> 将过期物品提醒送到你的微信。

---

## 当前方案：Server酱（已采用）

### 原理

```
HomeKeeper（APScheduler 定时扫过期物品）
  → POST 到 Server酱 API
  → Server酱 转发到你的微信服务通知
  → 你在微信里看到消息
```

### 配置步骤

1. **注册**：打开 [sct.ftqq.com](https://sct.ftqq.com) → 微信扫码登录
2. **复制 SendKey**：登录后页面会自动生成
3. **填到 `.env`**：
   ```bash
   SERVERCHAN_SENDKEY=你的SendKey
   ```
4. **重启**：`docker compose up -d --build`

### 效果

消息出现在微信「服务通知」里：

```
📦 3 件物品即将过期
━━━━━━━━━━━━━━━━━━
🔴 牛奶 — 还有 1 天过期
🟡 鸡蛋 — 还有 5 天过期
🟡 面包 — 还有 3 天过期
━━━━━━━━━━━━━━━━━━
请及时处理。
```

## 备选方案（后续评估）

以下方案已调研完毕，后续需要时可切换：

| 方案 | 说明 | 适用场景 | 复杂度 |
|------|------|---------|--------|
| **企业微信自建应用** | 用 CorpID/AgentID/Secret 调 API 发应用消息 | 不想依赖第三方，完全自控 | ⭐⭐⭐ 需配 IP 白名单 |
| **企业微信群机器人 Webhook** | 群设置 → 添加机器人 → 获得 webhook URL | 需要发消息到企业微信群 | ⭐ 简单，但仅限内部群 |
| **APK 轮询** | 安卓 App 定时调 HomeKeeper API 弹本地通知 | 自己做 APK 时顺带实现 | ⭐⭐ APK 开发量 |
| **WebSocket 自建推送** | 服务器和 APK 保持长连接，实时推送 | 需要实时推送时 | ⭐⭐⭐ 需开发服务端 |
| **微信群自然语言交互** | 群内发「牛奶还有多久过期」→ 机器人自动回复 | 企业微信回调 + NLP 解析 | ⭐⭐⭐⭐ 大工程 |

## 更换推送通道

HomeKeeper 的推送架构设计为「一个调度器 + 多个通道」：

```
APScheduler 定时器
  └── _check_all_users()
        ├── Web Push（浏览器推送，已实现）
        └── Server酱 → 微信（当前方案）
        ├── 企业微信（备选）
        ├── APK 轮询（备选）
        └── ...
```

更换通道只需修改 `push.py` 中的 `_send_wecom()` 函数，无需改动定时器逻辑。

# 开发指南

面向后续维护与功能扩展。遵循「分层 + 模块化」，新增功能不需要改动既有结构。

---

## 目录结构

```
homekeeper/
├── README.md                  # 总导航
├── docker-compose.yml / Dockerfile / .env.example / requirements.txt
├── data/                      # SQLite（卷挂载）
├── app/
│   ├── main.py                # 入口：路由挂载 / 静态 / CORS / lifespan
│   ├── config.py              # 读 .env
│   ├── database.py            # 引擎 / Session / Base / init_db / get_db
│   ├── deps.py                # get_current_user（JWT 校验）
│   ├── core/security.py       # 密码哈希 + JWT
│   ├── models/                # ORM（每表一文件 + __init__ 汇总）
│   ├── schemas/               # Pydantic 请求/响应
│   ├── routers/               # 路由（按资源拆分，/api 前缀）
│   └── static/                # 原生前端（html/css/js 模块化）
├── tests/                     # pytest
└── docs/                      # 专项文档
```

---

## 分层约定

| 层 | 职责 | 不做什么 |
|----|------|---------|
| `models` | SQLAlchemy ORM 定义 | 不写业务逻辑 |
| `schemas` | 请求/响应校验与序列化 | 不碰数据库 |
| `routers` | 接收请求、调用、返回 | 复杂逻辑下沉到 `services/`（预留） |
| `core/security` | 密码 + JWT | — |
| `static` | 原生前端，通过 `api.js` 调后端 | 不直连数据库 |

---

## 如何新增一个资源（示例：品牌 Brand）

1. **模型**：`app/models/brand.py` 定义 `Brand(Base)`，并在 `app/models/__init__.py` 导入。
2. **Schema**：`app/schemas/brand.py` 定义 `BrandCreate / BrandUpdate / BrandOut`。
3. **路由**：`app/routers/brands.py` 写 CRUD，所有写操作加 `current_user: User = Depends(get_current_user)` 做数据隔离。
4. **注册**：`app/main.py` `app.include_router(brands.router)`。
5. **前端**：加 `app/static/js/brands.js` 与 `index.html` 导航项（参考 `items.js`）。

> 保持每资源「model + schema + router」三件套，结构一致即可维护。

## API 约定

- 统一前缀 `/api`，标签按资源（`tags=["items"]` 等）。
- 鉴权：`Authorization: Bearer <token>`；未带/失效返回 401。
- 响应使用 `response_model`，过滤字段统一。
- 错误：`raise HTTPException(status_code=..., detail="中文说明")`。

## 本地运行

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
# 浏览器访问 http://127.0.0.1:8000
```

## 测试

```bash
pip install -r requirements.txt
pytest
```

测试使用 `httpx` + `fastapi.testclient` 的 `TestClient`，覆盖注册/登录与物品 CRUD。

## 代码规范

- 后端 Python：全程类型注解；枚举用 `str, enum.Enum`（中文值需前后端一致）。
- 前端：原生 ES Module，`api.js` 统一封装 `fetch` 与令牌；视图逻辑拆分到各 `js` 模块。
- 配置一律走 `.env` / 环境变量，不硬编码密钥。
- 新增坑及时补 [踩坑与排错](docs/03-踩坑与排错.md)；发版更新 [更新日志](docs/02-更新日志(CHANGELOG).md)。

# 安卓端规划

本文档为后续安卓客户端（远程连接 HomeKeeper 服务器）预留接口与方案，后端 v0.1 已具备所需 REST API。

---

## 一、目标

安卓 App 通过 HTTPS 远程调用服务器 API，实现：物品增删改查、位置/分类管理、过期提醒推送。
后端无需为安卓端单独开发接口——复用同一套 REST API 即可。

---

## 二、鉴权流程

1. 登录拿令牌
   ```
   POST /api/auth/login
   Content-Type: application/x-www-form-urlencoded
   body: username=xxx&password=xxx
   → { "access_token": "...", "token_type": "bearer" }
   ```
2. **安全存储**：`access_token` 存入 `EncryptedSharedPreferences` 或 Android Keystore，**不要**明文存 SP。
3. 后续请求携带：
   ```
   Authorization: Bearer <access_token>
   ```
4. 令牌过期（默认 1 天）返回 401 → 重新登录（refresh token 至今未实现，属后续版本计划）。

---

## 三、安卓端使用的 API 清单

| 方法 + 路径 | 用途 |
|------------|------|
| `POST /api/auth/login` | 登录取 token（账号由管理员创建，无公开注册）|
| `GET /api/auth/me` | 校验/获取当前用户 |
| `GET/POST /api/items`；`GET/PUT/DELETE /api/items/{id}` | 物品 |
| `GET/POST /api/locations`；`PUT/DELETE /api/locations/{id}` | 位置层级 |
| `GET/POST /api/categories`；`PUT/DELETE /api/categories/{id}` | 分类 |
| `GET /api/dashboard/summary` | 统计 |
| `GET /api/dashboard/expiring?days=30` | 过期提醒 |

> 完整字段见 [功能说明 · 数据模型](docs/01-功能说明.md) 与运行时 `/docs`。

---

## 四、远程连接要点

- **服务器必须 HTTPS**（见 [部署指南 · Nginx 反代](docs/04-部署指南.md)），安卓端禁止明文 HTTP。
- **CORS**：若 App 以独立来源调用，把服务器 `.env` 的 `CORS_ORIGINS` 设为你的域名（不要用 `*`）。
- **网络**：家庭宽带宽带公网 IP 可能变动，建议配合域名 + DDNS，或云服务器固定 IP。
- **证书**：自签证书需在 App 内配置信任；推荐 Let's Encrypt 免费证书。

---

## 五、数据模型对应

安卓端实体字段与后端 `Item / Location / Category / User` 一致：

| 后端字段 | 安卓端 |
|---------|--------|
| `Item.name/quantity/unit/status/expiry_date/...` | `Item` 实体 |
| `Item.location_id` + `location_note` | 位置（层级 + 备注） |
| `Item.category_id` | 分类 |
| `ItemStatus` 中文枚举 | 同值枚举 |

---

## 六、离线缓存预留（规划中）

- 本地用 **Room** 缓存物品/位置/分类，断网可读。
- 写操作先落本地、标记待同步，网络恢复后批量同步到服务器（需后端补充冲突处理/版本字段）。
- 过期提醒可用 WorkManager 定时拉 `/api/dashboard/expiring` 并推送通知。

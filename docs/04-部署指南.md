# 部署指南

---

## 一、Docker 一键部署（推荐）

```bash
# 1. 准备配置
cp .env.example .env
# 修改 SECRET_KEY 为随机长字符串：
# python -c "import secrets;print(secrets.token_hex(32))"
# 修改 DEFAULT_ADMIN_PASSWORD 为强密码（首次启动的 admin 登录密码）：
# python -c "import secrets;print(secrets.token_urlsafe(12))"

# 2. 构建并后台启动
docker compose up -d --build

# 3. 访问
# 浏览器打开 http://<服务器IP>:8000
# 使用管理员账号 admin 登录（密码为第 1 步设置的 DEFAULT_ADMIN_PASSWORD）
# 未设置 DEFAULT_ADMIN_PASSWORD 时，启动日志会打印随机生成的管理员密码，登录后请立即修改
# 默认禁止公开注册，管理员登录后在「管理」页创建用户
# API 文档：http://<服务器IP>:8000/docs
```

数据文件：`./data/homekeeper.db`（已卷挂载，重启不丢）。

## 二、远程访问

### 方案 A：家庭 / 内网直连
- 在路由器做端口转发，把外网端口映射到服务器 `8000`。
- 仅内网或临时使用，**不建议公网明文暴露**。

### 方案 B：域名 + HTTPS（公网推荐）

用 Nginx 反代并加 TLS（证书可用 Let's Encrypt / acme.sh）：

```nginx
server {
    listen 443 ssl;
    server_name home.example.com;

    ssl_certificate     /etc/nginx/ssl/home.example.com/fullchain.pem;
    ssl_certificate_key /etc/nginx/ssl/home.example.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

> 安卓端走 HTTPS 域名调用 API，避免明文与证书问题（见 [安卓端规划](docs/06-安卓端规划.md)）。
> 若安卓端跨域，把 `.env` 的 `CORS_ORIGINS` 设为你的域名（逗号分隔），不要用 `*`。

## 三、数据备份

SQLite 是单文件，直接复制即可：

```bash
# 停服备份（或在线复制，SQLite 支持快照）
cp data/homekeeper.db ~/backups/homekeeper-$(date +%F).db
```

定时备份（`crontab -e`）：

```cron
0 4 * * * cp /path/to/homekeeper/data/homekeeper.db /backups/homekeeper-$(date +\%F).db
```
